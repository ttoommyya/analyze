# データの配置

`data/` 配下はこのREADME以外、すべてGitの対象から除外されます。
必要に応じてローカルに以下を作成してください。

- `raw/`: 取得した生データ。原本は変更しない。
- `interim/`: 中間処理データ。
- `processed/`: 解析用に整形したデータ。

データ本体は別の管理先に保存し、取得元、取得日、サンプルID、ファイルのSHA-256、
前処理方法を記録してください。公開できる取得手順はこのREADMEに追記できます。
実データ・顕微鏡画像・個人情報を含むファイルを `git add -f` で追加しないでください。
テストには人工的な小さいデータを用い、実データのコピーを利用しないでください。
